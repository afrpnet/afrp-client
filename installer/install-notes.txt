AFRP OIDC Client 安装前说明

一、这个程序是什么
  使用 afrp.net 账号登录，选择服务器，一键建立 frpc 隧道。
  隧道配置（服务器地址、端口、token 等）由程序从服务器自动获取并经 OIDC 认证自动填充，
  内置 frpc 客户端由程序自动释放和启动，无需手动配置任何文件。

二、关于"内置 frpc 被安全中心拦截"的说明
  1. 本程序内置 frp 官方开源客户端 frpc（v0.71.0），属于正常的隧道组件。
  2. 程序首次连接服务器时会把它释放到：
       %APPDATA%\net.afrp\AFRP OIDC Client\frpc\
     并在连接期间启动它。若无任何安全软件拦截，这一步完全无感。
  3. Windows 安全中心（Microsoft Defender）对 frpc 的云端判定为"潜在不受欢迎的应用"
     （PUA:Win32/FRProxy，分类为代理工具，并非病毒代码）。在开启了实时防护的机器上，
     安装或运行过程中它可能被隔离，表现为程序提示 frpc 释放失败或隧道无法启动。
  4. 为此安装程序默认勾选"添加 Windows 安全中心排除项"，会在复制文件之前尝试自动把
     安装目录和上述 %APPDATA% 缓存目录加入排除项。
     如果失败（例如没有管理员权限、"篡改防护"处于开启状态、或系统未安装 Defender），
     安装完成后会弹出提示，请在 Windows 安全中心里手动添加这两个文件夹：
       Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项 → 添加或删除排除项
       → 添加排除项 → 文件夹，加入：
         安装目录（默认 C:\Program Files\AFRP OIDC Client）
         %APPDATA%\net.afrp\AFRP OIDC Client\frpc
  5. 本安装包未做数字签名，首次运行若出现"Windows 已保护你的电脑"（SmartScreen）提示，
     请点击"更多信息"→"仍要运行"。

三、卸载说明
  卸载程序会移除安装目录、开始菜单和桌面快捷方式，并从安全中心移除本程序添加过的排除项。
  用户数据（登录状态、偏好设置、frpc 缓存）保留在：
    %APPDATA%\net.afrp\AFRP OIDC Client\
  如需彻底清理，请在卸载后手动删除该文件夹。
