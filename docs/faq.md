# 常见问题 FAQ

## 登录与站点地址

**Q：登录提示连接失败 / 一直转圈怎么办？**
A：App 默认连接官方站点（`https://www.afrp.net`），登录页不再提供服务器设置。
自建站点请登录后在「设置 → 服务器地址」修改（需带 `http://` 或 `https://` 前缀，
不要填 `/api` 等路径），保存后重新登录。
登录页底部会显示当前「认证服务」地址，可据此确认连接目标；
首次打开时请检查网络是否可访问该站点。

**Q：账号密码是什么？需要单独注册吗？**
A：不需要。App 与网站共用账号体系，使用网页端相同的用户名（或邮箱）+ 密码登录。

**Q：登录状态会过期吗？**
A：本机保存的登录令牌长期有效；若在网页端修改密码或在服务端被注销，需要重新登录。

## 连接与密钥

**Q：点「连接服务器」后状态是「认证/连接失败，请看日志」，怎么办？**
A：看「运行日志」最后几行：
- `authentication failed` / `login to server failed`：密钥与服务端不一致，
  请重新「粘贴已有密钥」或「一键生成新密钥」；
- `connect to server error`：网络到服务器不通，检查网络或服务器的地址和端口；
- 提示「账号未开启 OIDC 认证」：联系管理员在后台为该账号开启。

**Q：密钥（Client Secret）保存在哪里？安全吗？**
A：明文只保存在**本机系统安全存储**（加密），服务端只保存哈希；
密钥用于 frpc 向服务器做 OIDC 认证，等同于该账号的穿透凭证，请勿泄露。

**Q：点「一键生成新密钥」会有什么影响？**
A：旧密钥**立即失效**，所有仍在使用旧密钥的客户端会断开。
如果有多台设备，正确做法是：在一台设备上生成，然后把新密钥复制到其他设备
（其他设备用「粘贴已有密钥」）。

**Q：换了电脑 / 重装了系统，需要做什么？**
A：重新登录；密钥如在服务端未变，可从网页端复制后「粘贴已有密钥」，
否则重新生成；隧道配置保存在本机、不随账号同步，需要重新添加。

**Q：同一时刻能连接几个服务器？**
A：一个。App 同一时间只运行一个 frpc 进程；切换服务器前请先断开。

## 平台支持

**Q：Android / 鸿蒙版为什么连不上，提示「当前平台暂不支持内置 frpc」？**
A：这两个平台目前是测试版，连接功能将在后续版本提供；
当前可以使用登录、会员购买、消息和设置，隧道也可以提前配置、后续版本直接复用。

**Q：有 iOS / Linux / macOS 版吗？**
A：iOS 规划中（需要 macOS 构建环境与 Apple 签名）；Linux / macOS 源码可自行构建，
未提供官方安装包。见 [安装说明](install.md)。

**Q：桌面图标名称能改吗？**
A：桌面/任务栏图标名称是安装包内固定的「AFRP OIDC Client」，改后台的 App 名称 / 站点名称**不会**
改变它（窗口标题会跟着变）。如需更换图标名称需重新打包。

## 会员与支付

**Q：会员页显示「开通会员功能暂未开放」？**
A：站点后台关闭了会员购买入口，请联系管理员。

**Q：支付了但会员没开通？**
A：按支付方式区分：
- 扫码 / 跳转链接：支付面板会自动查询，也可点「我已支付，立即查询」；
- 加密币（USDT）：必须**精确转账订单显示的金额**（自动核对的唯一依据），
  一般 1-3 分钟自动到账开通；金额不符则无法自动核对，需联系管理员处理。
- 可在「订单记录」确认订单状态；长期未开通请联系管理员并提供订单号。

**Q：关闭支付面板后订单去哪了？**
A：待支付订单会保留在会员页顶部，点「继续支付」可重新发起；也可在订单记录中点它续付。

## 管理员：如何自定义 App 名称与 Logo

客户端启动时会从站点接口拉取配置，各平台表现一致。
后台「系统 → APP 设置」管理 App **专属**的名称与 Logo，与「系统 → 系统管理」中的
网站设置相互独立：留空或选择「跟随系统」时自动使用系统设置，自定义后只影响 App，
不会改变网站显示（页面底部有 App 实际获取内容的实时预览）。

1. 登录网站后台，进入「系统 → APP 设置」页面：
   - **App 名称**（留空跟随系统）：App 窗口标题、设置页「关于 - 站点」、
     登录页图片 Logo 下方的标题都使用它；未设置时客户端显示默认名「AFRP OIDC」。
   - **App Logo**，三选一：
     - **跟随系统设置**：与网站使用相同的 Logo（默认）；
     - **文字 Logo（App 专属）**：两段文本（如 `afrp` + `.net`），App 中用同款配色渲染
       （第一段主题橙 `#FF7452`，第二段绿色 `#1CC88A`，Comfortaa 加粗字体）；
       文字 A 留空则改为显示 App 名称纯文字；
     - **图片 Logo（App 专属）**：填写图片地址，支持相对路径（如 `/assets/logo.png`）或
       完整 URL；建议使用透明背景 PNG，高度按 64 逻辑像素内展示；留空或加载失败时回退文字展示。
2. OIDC 认证参数（Issuer / Audience / Scope）在「系统 → 系统管理」中配置，
   App 连接时自动填入，用户无需手填；需与 frps.toml 保持一致。
3. 会员开关在「会员与支付 → 套餐管理」中配置，控制 App 内是否显示会员模块。
4. 保存后，用户**重新打开客户端或重新登录**即可看到新名称 / Logo；
   图片加载失败时会自动回退到文字 Logo。
5. 注意：这只影响客户端内显示与窗口标题；安装包文件名、桌面快捷方式名称在打包时固定，
   不会随后台设置变化。

## Windows 其他

**Q：首次打开提示「Windows 已保护你的电脑」？**
A：未签名程序的 SmartScreen 提示，点「更多信息」→「仍要运行」即可。

**Q：杀毒软件报警？**
A：frpc 为网络穿透工具，部分杀软会误报。可将程序目录加入白名单；
macOS 版已将 frpc 以压缩包形式分发以降低误报概率。

**Q：隧道配置会丢失吗？换台电脑能同步吗？**
A：不会丢（保存在本机，退出登录也保留），但**不随账号同步**，换设备需重新配置。
