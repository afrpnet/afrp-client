# 常见问题 FAQ

## 登录与站点地址

**Q：登录提示连接失败 / 一直转圈怎么办？**
A：App 默认连接官方站点（`https://www.afrp.net`），登录页不再提供服务器设置。自建站点请登录后在「设置 → 服务器地址」修改（需带 `http://` 或 `https://` 前缀，不要填 `/api` 等路径），保存后重新登录。登录页底部会显示当前「认证服务」地址，可据此确认连接目标；首次打开时请检查网络是否可访问该站点。

**Q：账号密码是什么？需要单独注册吗？**
A：不需要。App 与网站共用账号体系，使用网页端相同的用户名（或邮箱）+ 密码登录。

**Q：登录状态会过期吗？**
A：本机保存的登录令牌长期有效；若在网页端修改密码或在服务端被注销，需要重新登录。

## 连接与密钥

**Q：点「连接服务器」后状态是「认证/连接失败，请看日志」，怎么办？**
A：看「运行日志」最后几行：
- `authentication failed` / `login to server failed`：密钥与服务端不一致，请重新「粘贴已有密钥」或「一键生成新密钥」；
- `connect to server error`：网络到服务器不通，检查网络或服务器的地址和端口；
- 提示「账号未开启 OIDC 认证」：联系管理员在后台为该账号开启。

**Q：密钥（Client Secret）保存在哪里？安全吗？**
A：明文只保存在**本机系统安全存储**（加密），服务端只保存哈希；密钥用于 frpc 向服务器做 OIDC 认证，等同于该账号的穿透凭证，请勿泄露。

**Q：点「一键生成新密钥」会有什么影响？**
A：旧密钥**立即失效**，所有仍在使用旧密钥的客户端会断开。如果有多台设备，正确做法是：在一台设备上生成，然后把新密钥复制到其他设备（其他设备用「粘贴已有密钥」）。

**Q：换了电脑 / 重装了系统，需要做什么？**
A：重新登录；密钥如在服务端未变，可从网页端复制后「粘贴已有密钥」，否则重新生成；隧道配置保存在本机、不随账号同步，需要重新添加。

**Q：同一时刻能连接几个服务器？**
A：一个。App 同一时间只运行一个 frpc 进程；切换服务器前请先断开。

## 平台兼容性

**Q：Linux 版运行提示 GLIBC 版本不够？**
A：当前构建基于 Ubuntu 22.04（GLIBC 2.35），兼容 Debian 12+、Ubuntu 20.04+、CentOS 9 等。如果你的系统 GLIBC 低于 2.35，请升级系统或用 Docker 运行。

**Q：HarmonyOS NEXT 真机能安装吗？**
A：不能。当前 HAP 使用 OpenHarmony 测试签名，仅支持 OpenHarmony 设备/模拟器。HarmonyOS NEXT 真机需要华为开发者账号的云签名。

**Q：有 iOS 版吗？**
A：iOS 规划中，需要 macOS 构建环境与 Apple 签名。

**Q：桌面图标名称能改吗？**
A：桌面/任务栏图标名称是安装包内固定的「AFRP OIDC Client」，改后台的 App 名称不会改变它（窗口标题会跟着变）。如需更换图标名称需重新打包。

## Windows 其他

**Q：首次打开提示「Windows 已保护你的电脑」？**
A：未签名程序的 SmartScreen 提示，点「更多信息」→「仍要运行」即可。

**Q：杀毒软件报警？**
A：frpc 为网络穿透工具，部分杀软会误报。安装版可在安装时自动添加 Defender 排除项；也可手动将程序目录加入白名单。

**Q：隧道配置会丢失吗？换台电脑能同步吗？**
A：不会丢（保存在本机，退出登录也保留），但**不随账号同步**，换设备需重新配置。
