# 用户手册

适用于全部平台（Windows / Android / 鸿蒙 / 未来的 iOS、Linux、macOS）。
界面在各平台一致，差异仅在「连接」功能是否可用，见 [平台支持矩阵](README.md#平台支持矩阵)。

## 界面总览

登录后进入主界面，共 4 个页签：

| 页签 | 用途 |
| --- | --- |
| 连接 | 选服务器、配置隧道、一键连接、查看运行日志 |
| 会员 | 查看会员状态、购买套餐、查看订单 |
| 消息 | 站内信（未读提醒） |
| 设置 | 账号信息、服务器地址、OIDC 密钥、关于、退出登录 |

后台「套餐管理」关闭「开通会员」后进入测试模式：仅「测试人员」名单内的账号
可见「会员」页签并购买，其他账号该页签整体隐藏，与网站行为一致。名单在后台
「套餐管理 → 测试模式」中配置（每行一个用户名）。

电脑宽屏为左侧边栏导航，手机窄屏为底部导航栏。「消息」有未读时图标上显示角标
（超过 99 显示 99+），App 每 60 秒自动刷新一次未读数。

## 首次使用（四步）

1. **登录**：输入网页端账号（用户名或邮箱）和密码。App 默认连接官方站点
   `https://www.afrp.net`；如需改用自建站点，登录后在「设置 → 服务器地址」修改
   再重新登录。登录成功后登录状态会保存在本机，下次打开自动登录。
2. **设置 OIDC 密钥**：在「连接」页的 OIDC 认证卡片中，选择
   「粘贴已有密钥」（从网页端复制）或「一键生成新密钥」。
3. **选服务器、加隧道**：在「连接」页选择服务器，点「添加隧道」，按要穿透的服务
   填写（例如把本机 127.0.0.1:3389 映射到远程端口 13389）。
4. **连接**：点「连接服务器」，状态变为「已连接（隧道已启动）」即成功；
   下方运行日志会显示详细过程。

## 登录页

- **账号 / 邮箱**、**密码**：与网页端一致。
- 页面底部显示当前「认证服务」地址（来自站点配置的 OIDC Issuer），
  站点地址的修改已移至登录后的「设置 → 服务器地址」。
- 页面顶部品牌区（名称 / Logo）由站点后台配置：后台「APP 设置」可单独为 App 定制
  （与网站显示相互独立，留空 / 跟随系统时使用网站设置），见
  [FAQ：自定义 App 名称与 Logo](faq.md#管理员如何自定义-app-名称与-logo)。

## 连接页

### 服务器

- 下拉选择服务器（显示名称、地址、地区），右侧标签显示账号分组（免费 / VIP / SVIP / Pro）。
- 选中后下方显示地址、认证方式（OIDC）、子域名（若服务器提供）等信息。
- 免费账号可能只显示部分节点；点右上角刷新按钮可重新获取列表。
- 连接过程中不能切换服务器，需先断开。

### OIDC 认证（自动填充）

账号密码登录 App 后，frpc 连接所需的 OIDC 认证字段由 App 自动写入配置，
本卡片仅展示当前将使用的值：认证方式、用户名（clientID）、Token Endpoint、
Audience、Scope。需要你手动处理的是 **Client Secret（密钥）**：

- **粘贴已有密钥**：从网页端「连接说明」复制密钥粘贴进来；密钥只保存在本机系统安全存储。
- **一键生成新密钥**：在服务端生成新密钥并自动保存到本机。
  注意：**旧密钥立即失效**，所有使用旧密钥的客户端会断开；
  生成后密钥明文只显示一次，请妥善保存（服务端只存哈希）。
- **清除本机密钥**：仅删除本机保存的副本（服务端密钥不变）。
- 卡片提示「服务器上已存在密钥但本机未保存」时，说明以前设置过密钥，
  可粘贴旧密钥或重新生成（重新生成会使其他设备上的旧密钥失效）。
- 提示「账号未开启 OIDC 认证」时无法连接，需联系管理员开通。

### 隧道

点「添加隧道」新建，名称仅支持字母、数字、`_`、`.`、`-`。类型共七种：

| 类型 | 需要填写 | 说明 |
| --- | --- | --- |
| TCP | 本地 IP、本地端口、远程端口 | 例如远程桌面：本地 3389 → 远程 13389 |
| UDP | 同上 | 例如游戏、语音服务 |
| HTTP | 本地 IP、本地端口、子域名/自定义域名 | 通过域名访问本机网站 |
| HTTPS | 同上 | 带证书的网站 |
| STCP | 本地 IP、本地端口、访问密钥 | 加密 TCP · P2P，不占服务器端口 |
| SUDP | 同上 | 加密 UDP · P2P，不占服务器端口 |
| XTCP | 同上 | 点对点直连（NAT 打洞），失败时经服务器转发 |

- 本地 IP 默认 `127.0.0.1`（即本机）。
- HTTP/HTTPS 隧道：服务器提供子域名时显示「子域名前缀」与可选的「自定义域名」，
  **两者都填时自定义域名优先**；服务器未提供子域名时只能填自定义域名。
  必须填子域名或自定义域名其中之一。
- STCP/SUDP/XTCP 隧道：访问密钥可用输入框右侧的骰子按钮随机生成；
  该类型不占用服务器端口，访问方需以 visitor 方式、用相同密钥与隧道名称连接
  （访问方配置不在本 App 内，参见 frp 官方文档）。
- 每条隧道右侧有「编辑」「删除」按钮，可随时修改；删除需确认。
- 隧道按服务器分别保存，只存在本机；退出登录不会丢失。
- 连接进行中不能增删改隧道，需先断开（连接时「编辑」「添加」按钮置灰）。

### 连接与状态

- 状态圆点：灰色=未连接，橙色=正在启动，绿色=已连接；右侧显示文字状态。
- 「连接服务器」/「断开连接」一键切换。点击连接前 App 会依次检查：
  账号已开启 OIDC、已保存本机密钥；若没有配置任何隧道，会询问是否仅验证登录连接。
- 「查看配置」：预览自动生成的 frpc.toml（密钥默认用圆点打码），
  可切换「显示密钥」或「复制完整配置」。内容包含服务器地址、user、
  auth.oidc.* 全部认证字段与每条隧道的 [[proxies]]。
- 底部显示 frpc 版本与当前运行平台。

### 运行日志

- 等宽字体实时滚动输出 frpc 日志，自动跳到最新一行；`error` / `failed` / `panic`
  行标红，`success` 行标绿。
- 状态判断依据：
  - `login to server success` → 已连接；
  - `start proxy success` → 已连接（隧道已启动）；
  - `login to server failed` / `connect to server error` / `authentication failed`
    → 认证/连接失败，请看日志；
  - `[进程已退出，代码 N]` → 连接中断（代码 0 为正常断开）。
- 右上角「清空」只清空显示，不影响连接。

## 会员页

### 会员状态

顶部卡片显示头像、用户名、邮箱与分组徽标（免费 / VIP / SVIP / Pro / 管理员）；
下方只列出**已开通**的会员等级及到期时间（「永久」或 `yyyy-MM-dd 到期`，
已过期显示 `yyyy-MM-dd 已过期`），未开通的等级不显示。

### 购买套餐

- 若「开通会员功能暂未开放」横幅出现，说明站点后台关闭了购买入口，请联系管理员。
- 套餐卡按分组展示，每个周期一个价格，点「购买」后先选择支付方式，再进入支付面板。
- 三种支付方式对应的面板：
  - **跳转链接**：点「打开支付页面」跳转浏览器支付，支付完成后面板自动确认；
    也可复制链接到其他设备打开。
  - **扫码支付**：显示二维码（微信/支付宝，按所选方式），用手机扫码支付；
    面板每 3 秒自动查询一次到账情况，支付后自动开通。
  - **加密币（USDT）**：显示网络（如 USDT-TRC20）、收款地址、转账金额、参考汇率。
    **务必按「转账金额」精确转账**（金额是自动核对到账的唯一依据），
    转账后一般 1-3 分钟自动到账并开通；面板每 8 秒自动核对链上到账。
- 面板按钮：「我已支付，立即查询」手动立即查询；「稍后支付」关闭面板（订单保留）；
  「取消订单」作废本次订单。
- 关闭面板不影响订单：待支付订单会显示在会员页顶部，可点「继续支付」重新发起。

### 订单记录

页面底部「订单记录」折叠卡显示最近订单（订单号、套餐、支付方式、金额、状态）。
点击待支付订单可直接继续支付。

## 消息页

- 未读消息加粗高亮显示，点击展开全文并标记已读。
- 右上角「全部已读」一键清空未读；「刷新」重新拉取；也可下拉刷新。
- 每条消息右侧可删除（需确认）。列表为空时显示「暂无消息」。

## 设置页

| 区块 | 内容 |
| --- | --- |
| 账号 | 用户名、邮箱、OIDC 认证开关、服务器密钥状态；可刷新 |
| 服务器地址 | 修改站点地址，「保存并测试连接」即时校验 |
| OIDC 密钥 | 与连接页相同的密钥管理（粘贴 / 生成 / 清除） |
| 关于 | 站点（后台设置的名称）、App 版本、frpc 版本、运行平台 |
| 退出登录 | 需确认；连接中会先断开；本机隧道配置不丢失 |

## 本机数据保存在哪

- 隧道配置、所选服务器、站点地址保存在本机应用数据目录；
- 登录令牌与 OIDC 密钥保存在本机系统安全存储（加密）；
- 这些数据**不会**上传到服务器，换设备后需要重新登录、重新配置密钥和隧道
  （服务端密钥不变时，可在新设备「粘贴已有密钥」）。
- Windows 上数据目录为 `%APPDATA%\net.afrp\AFRP OIDC Client\`：
  - `shared_preferences.json` — 站点地址、所选服务器、隧道配置；
  - `flutter_secure_storage.dat` — 加密保存的登录令牌与 OIDC 密钥；
  - `frpc\` — 首次连接时自动释放的 frpc.exe 和生成的 frpc.toml。
  删除该目录等于重置 App 本机数据（需重新登录并重新配置）。
